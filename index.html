1. 변수와 범위 (let vs var)

변수는 값을 담는 상자예요. 그런데 상자가 보이는 범위가 다릅니다.

letvar
범위{ } 블록 안에서만 유효블록을 무시하고 바깥까지 유효
같은 이름 다시 선언블록 안의 let은 새 상자를 만듦같은 상자를 다시 쓰는 것
비유: let은 교실 안에서만 쓰는 이름표, var은 학교 전체에서 통하는 이름표.
let x = 100;
if (x > 50) { let x = 10; }   // 블록 안의 새 x
console.log(x);               // 100 (바깥 x는 그대로)

2. 이벤트

이벤트 = 사용자가 클릭, 키 입력 등을 했을 때 브라우저가 자바스크립트에게 알려주는 통지.
이벤트 리스너 = 그 통지를 처리하는 코드. (mousedown 이벤트 → onmousedown 리스너)
이벤트 타겟 = 이벤트를 일으킨 DOM 객체. 이벤트 객체 = 이벤트 정보(타겟, 마우스 위치, 버튼 등)를 담은 객체.

리스너 등록 3가지 방법

<p onclick="alert('hello')">      // 1. HTML 태그 안에 직접
p.onclick = function(e){ alert("hello") }       // 2. 프로퍼티에 등록
p.addEventListener("click", function(e){ alert("hello") }) // 3. 메소드로 등록
주의! addEventListener의 이벤트 이름에는 on을 붙이지 않아요. ("click" O, "onclick" X)

4. 함수, 배열, 문자열

함수와 콜백

함수도 값이라서 다른 함수에 전달할 수 있어요. 이렇게 전달하는 함수가 콜백 함수.

function callThreeTimes(callback){ for(let i=0;i<3;i++) callback(i) }
function print(i){ console.log(`${i}번째 함수 호출`) }
callThreeTimes(print)   // 0번째, 1번째, 2번째

익명 함수(function(){})와 선언적 함수(function f(){}) 이름이 같으면, 실행 순서상 나중에 대입한 값이 이깁니다.

템플릿 리터럴

백틱(`)과 ${변수}로 문자열을 편하게 만들어요. `${a} ${c} ${b}`

++ 와 -- (앞 / 뒤)

number++ = 쓰고 나서 올림 / ++number = 올리고 나서 씀.

배열 (Array)

객체는 new로 만들어요. new Array("jan","Feb")와 ["jan","Feb"]는 같습니다. length는 개수이고, 값을 대입하면 배열 크기를 늘릴 수 있어요.

forEach · filter

numbers.forEach((n, index) => { ... })        // 하나씩 꺼내 실행
numbers.filter((x) => x % 2 == 1)             // 조건에 맞는 것만 모은 새 배열

이미지 클릭할 때마다 90도 회전
var n = 90;
function rotate(obj){
  obj.style.transform = "rotate(" + n + "deg)";
  n += 90; n %= 360;
}
// <img onclick="rotate(this)">
배열의 최댓값 찾는 max()
const max = function(array){
  let output = array[0]
  for (const data of array){ if (output < data) output = data }
  return output
}
document.write(max([1,2,3,4]))   // 4

첫 값을 최댓값으로 두고, 더 큰 값을 만나면 바꾸는 방식이에요.

  let mySize = document.getElementById("size");
  if (e.wheelDelta > 0){ img.width -= img.width*0.05; img.height -= img.height*0.05 }
  else { img.width += img.width*0.05; img.height += img.height*0.05 }

이미지 커서 만들기 (onmousemove)
function makeCursor(){
  cursor = document.getElementById("cursor");
  cursor.style.zIndex = 100;   // 맨 위에 보이게
  document.onmousemove = function(e){
    cursor.style.left = e.clientX + "px";
    cursor.style.top  = e.clientY + "px";
  }
}
